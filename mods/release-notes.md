## Mod de Pet Soccer

Ce zip contient le mod, pas le jeu : il te faut Pet Soccer (Techland, 2002) installé sur ton PC.

### 1. Installer le jeu

Si tu as le jeu en ISO : clic droit sur le fichier, puis **Monter**, puis lance l'installation.

### 2. Installer le mod

1. Télécharge **`PetSoccerMod-update.zip`** plus bas, dans *Assets*.
2. Ferme le jeu, puis **décompresse tout le zip** dans un dossier. Ne lance pas l'installeur depuis l'aperçu du zip.
3. Double-clique sur **`Installer.bat`**. Il trouve le dossier du jeu (ou te le demande), garde les fichiers d'origine
   dans `mod_backup`, puis installe le mod.
4. Lance le jeu avec le raccourci **« Pet Soccer (mod) »** créé sur le bureau (ou `Jouer.bat`, dans le dossier du jeu).

> Si Windows affiche « Windows a protégé votre ordinateur » : *Informations complémentaires*, puis *Exécuter quand même*.
> Le script est lisible : ouvre `install.ps1` avec le Bloc-notes pour voir ce qu'il fait.

### 3. Mises à jour : automatiques

Tu n'as plus rien à télécharger. À chaque lancement par le raccourci **« Pet Soccer (mod) »**, une petite fenêtre
cherche une nouvelle version du mod ici. Si elle en trouve une, elle l'installe, puis le jeu se lance.

- Tes sauvegardes, ton compte en ligne et l'adresse du serveur sont gardés.
- Sans Internet, le jeu se lance quand même avec la version déjà installée.
- La version installée est écrite au menu principal, sous le logo.
- Si tu lances le jeu avec son raccourci d'origine, le mod **n'est pas mis à jour**.

Pour jouer en ligne, tout le monde doit avoir la même version du mod. Passe toujours par le raccourci
« Pet Soccer (mod) » et tu seras à jour.

### Retirer le mod

Double-clique sur **`Desinstaller.bat`** : le jeu redevient comme avant. Tes sauvegardes restent en place.
